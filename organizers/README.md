# Материалы организаторов

`evaluate.py` — эталонный скрипт расчёта метрик задачи 7, выданный
организаторами участникам 18.09.2026. Лежит здесь без изменений:

```
sha256  655c71db8c2e4d2cd7680c40c768afacfdffff360401111c1a46df921551ffa3  evaluate.py
```

Как он используется в решении:

* `falcon/metrics.py` повторяет его протокол, а `tests/test_official_equivalence.py`
  на каждом прогоне тестов сверяет наши числа с его числами на одних данных;
* `scripts/verify_official.py` прогоняет его на локальной отложенной выборке
  и подбирает порог отказа по его же баллу (отчёт — `docs/official_check.json`).

Что из него следует для сдачи:

* `submission.csv` — **без заголовка**, `query_id` и десять `gallery_id`;
* верхний кандидат в `candidates.csv` засчитывается, если это та же машина,
  **с любой камеры**: вопрос о толковании F1 (docs/ВОПРОС_ОРГАНИЗАТОРАМ.md)
  этим закрыт.

Скрипту нужен `pandas` — он в `requirements-dev.txt`, в образ сервиса не входит.
