# ЗАДАЧА 1. Скачать датасет

**Зачем.** Без конкурсных данных нельзя обучить модель, а точность модели — это
45% итогового балла. Весь код уже написан и проверен, он ждёт только данные.

**Сколько займёт.** 20–40 минут, из них большая часть — скачивание архива.

## Шаг 1. Зайти в личный кабинет участника

Открыть сайт хакатона, где регистрировалась команда (Лидеры цифровой
трансформации), и войти под своей учётной записью.

Найти нашу задачу — **«Фалькон Тех»**, она же задача №7 про цифровой признак
транспортного средства.

## Шаг 2. Найти ссылку на данные

В ТЗ (раздел 5) написано: «Датасет для работы доступен по ссылке в личном
кабинете». Ищи раздел с материалами, данными или вложениями к задаче.

Ссылка ведёт не на один файл, а на **папку в облаке**. В этой папке, судя по
ответам организаторов на вопросы участников, лежит три вещи:

| Файл | Что это | Насколько нужен |
|---|---|---|
| архив датасета (`.zip`) | сами данные: кадры и разметка | обязательно |
| `evaluate.py` | их собственный скрипт расчёта метрики | очень желательно |
| `example_submission.zip` | пример правильно заполненных файлов сдачи | очень желательно |

**Скачай все три.** `evaluate.py` нужен, чтобы сверить нашу метрику с эталонной:
если наши числа разойдутся с их скриптом, лучше узнать об этом сейчас, а не
после сдачи.

Если в папке чего-то нет или ссылка не открывается — написать модератору
задачи в телеграм: **@DartJoni** (Алания Константин), либо в общий чат
поддержки **@help_lct**.

## Шаг 3. Создать папку

1. Открыть Проводник
2. Перейти на диск **D:**
3. Создать папку с именем **`falcon-data`**

Должен получиться путь: `D:\falcon-data`

Именно на диске D:, потому что на C: мало места, а датасет весит несколько
гигабайт.

## Шаг 4. Распаковать архив

Правой кнопкой по скачанному архиву → «Извлечь всё» → указать папку
`D:\falcon-data` → «Извлечь».

**Важный момент, где чаще всего ошибаются.** После распаковки открой
`D:\falcon-data` и проверь, что файлы лежат **прямо там**, а не внутри ещё одной
вложенной папки.

Правильно:

```
D:\falcon-data\
    train.csv
    test_query.csv
    test_gallery.csv
    images\          (много файлов .jpg)
    README.md
```

Неправильно (лишний уровень вложенности):

```
D:\falcon-data\
    dataset\
        train.csv
        images\
```

Если получилось как во втором случае — просто перетащи содержимое папки
`dataset` на уровень выше, в `D:\falcon-data`. Или ничего не трогай и скажи мне,
я поправлю путь в командах.

Туда же, в `D:\falcon-data`, положи скачанный `evaluate.py`.

## Шаг 5. Сказать мне «готово»

Дальше ничего делать не надо. Я сам проверю данные и запущу обучение.

Если хочешь проверить сам — открой PowerShell в папке проекта и выполни:

```powershell
.\.venv\Scripts\python.exe scripts\check_data.py D:/falcon-data
```

Скрипт ничего не меняет, только читает. Он проверит структуру папки, целостность
таблиц, откроет часть кадров, посчитает автомобили и камеры и в конце напишет
либо «датасет в порядке», либо список того, что не так.

# ЗАДАЧА 2. Установить Docker Desktop

**Зачем.** Раздел 6 ТЗ требует, чтобы решение запускалось одной командой
`docker compose up`, а раздел 13 — чтобы жюри могло его развернуть у себя. Это
часть критерия «инженерное качество», а он весит 15% оценки. Файлы `Dockerfile`
и `docker-compose.yml` я уже написал, но проверить, что сборка реально проходит,
без установленного Docker невозможно.

**Почему не срочно.** Это можно сделать в любой день до сдачи. Датасет важнее.

**Сколько займёт.** 20–30 минут, включая обязательную перезагрузку компьютера.

**Что понадобится.** Права администратора на этом компьютере.

## Шаг 1. Скачать

Открыть **docker.com**, раздел Docker Desktop, скачать версию для Windows
(кнопка «Download for Windows — AMD64»). Файл около 600 МБ.

## Шаг 2. Установить

Запустить скачанный `Docker Desktop Installer.exe`.

В окне установки будет галочка про **WSL 2** — оставить её включённой. WSL 2 это
подсистема Linux внутри Windows, Docker без неё работать не будет.

Нажать OK и дождаться окончания.

## Шаг 3. Перезагрузить компьютер

Установщик попросит сам. Перезагрузка обязательна.

## Шаг 4. Запустить и принять условия

После перезагрузки открыть Docker Desktop из меню «Пуск». При первом запуске он
покажет лицензионное соглашение — принять. Регистрироваться и создавать аккаунт
**не нужно**, можно закрыть предложение войти.

Подождать, пока в левом нижнем углу окна индикатор не станет зелёным с надписью
**«Engine running»**. Первый запуск может занять пару минут.

## Шаг 5. Сказать мне «докер готов»

Дальше я соберу образ и проверю, что всё работает.

## Если места на диске C: не хватит

Docker хранит свои данные на C: и займёт несколько гигабайт. Сейчас там свободно
около 41 ГБ, этого достаточно. Но если станет мало, в Docker Desktop есть
настройка переноса: Settings → Resources → Advanced → Disk image location →
указать папку на диске D:.
