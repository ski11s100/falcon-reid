# Чек-лист демонстрации

## До показа

- [ ] Сервис запускается на чистом компьютере по инструкции.
- [ ] Основной и резервный набор изображений доступны локально.
- [ ] База очищена от случайных тестовых записей.
- [ ] Экран демонстрации открыт, масштаб браузера проверен.
- [ ] Есть локальная копия презентации и резервное видео.
- [ ] Проверено время полного сценария — не больше трёх минут.

## Сценарий

1. Показать исходный кадр и объяснить, почему номер ненадёжен.
2. Добавить эталонный профиль автомобиля.
3. Добавить второй эталон того же автомобиля и показать рост счётчика наблюдений.
4. Выполнить поиск по изменённому кадру.
5. Показать Top-K, уверенность и вердикт.
6. Открыть заранее рассчитанные метрики.

## Три цикла проверки

- 26.09 — функциональная проверка: все действия пользователя и ошибочные форматы.
- 27.09 — проверка качества: сложные положительные и отрицательные пары.
- 28.09 — генеральная репетиция на другом компьютере по инструкции из README.
