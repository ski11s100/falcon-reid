# Веса модели

Сюда кладётся `best.pt` — чекпоинт, обученный на конкурсных данных.
Dockerfile копирует этот каталог в образ: во время инференса сеть недоступна,
поэтому веса должны быть внутри образа (раздел 8 ТЗ, ответ 39).

Получить чекпоинт:

```powershell
.\.venv\Scripts\python.exe falcon/train.py <каталог данных> --output runs/v1 --epochs 60
copy runs\v1\best.pt models\best.pt
```

Ограничение раздела 7 ТЗ — суммарный размер всех файлов весов, участвующих в
инференсе, не более 2 ГБ. ResNet50-IBN-a занимает около 107 МБ.
