# Статус проекта

## Обновление 16 сентября 2026 — v4

Реальный датасет доступен и проверен: 9 556 обучающих наблюдений, 1 541 автомобиль. Данные разделены по ID с объединением одинаковых кадров, чтобы они не попали в разные части. Сравниваются классический алгоритм, исходный ResNet18, полное короткое дообучение и осторожное обучение последнего блока на парах с разных камер. Точные метрики выбранных весов — в metrics.json архива v4; это локальная валидация, не закрытый тест.

18 тестов проходят, включая соответствие нейросетевой подготовки изображения обучению. Добавлены официальный экспорт query/gallery, его проверка и наглядный HTML-разбор ошибок. Веса в архиве экспериментальные, качество недостаточно для заявления о конкурентоспособности. Отказ ещё не откалиброван; нейросервис без порога не принимает совпадения. Docker с нейросетью и финальная презентация требуют отдельной проверки/обновления. Ниже сохранена история — её утверждения о недоступном датасете уже не актуальны.

## Обновление 15 сентября 2026 — v3

Добавлены CSV/BBox-конвейер, 512-мерный ResNet18 ReID с обучением и локальным checkpoint, расчёт mINP и отказа, экспорт/валидация, интеграция модели в HTTP API. 15 тестов пройдены; цикл ML дополнительно проверен на искусственных данных. Датасет 0 байт, реальных метрик нет. Docker engine недоступен. Подробный актуальный статус и оставшиеся работы: docs/RELEASE_V3.md.

Далее — исторический статус v1, не подтверждение готовности к конкурсу. Упоминания необходимости детектора устарели: ТЗ уже предоставляет BBox.

## Следующая контрольная точка

После получения данных: сначала запустить `scripts/dataset_audit.py`, затем зафиксировать split по vehicle_id и получить baseline через `scripts/evaluate.py`. Только после этого выбирать нейросетевую модель.
