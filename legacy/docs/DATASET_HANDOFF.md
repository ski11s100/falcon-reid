# Что передать вместе с датасетом

Чтобы не потерять день на уточнения, Семёну желательно передать одним сообщением:

1. Архив или путь к датасету.
2. Полное официальное ТЗ.
3. Описание каждого файла разметки и полей таблиц.
4. Главную метрику и правила финальной проверки.
5. Разрешено ли использовать предобученные модели и внешние данные.
6. Оборудование финальной проверки: CPU/GPU и доступная память.
7. Ограничение на время обработки и размер решения.

Предпочтительная структура изображений для текущих скриптов:

```text
dataset/
  vehicle_id_1/
    image_1.jpg
    image_2.jpg
  vehicle_id_2/
    image_1.jpg
```

Если структура будет другой, не нужно переименовывать файлы вручную: сначала адаптируем загрузчик под официальный формат.

После получения данных выполняем в таком порядке:

1. Аудит файлов и разметки.
2. Поиск дублей и возможных утечек.
3. Фиксация train/validation/test по vehicle_id.
4. Расчёт текущего baseline.
5. Выбор детектора и ReID-модели.
6. Обучение, hard-negative mining и калибровка порогов.
7. Анализ ошибок и интеграция лучшей модели в уже готовый сервис.
