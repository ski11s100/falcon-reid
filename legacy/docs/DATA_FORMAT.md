# Формат данных

До публикации официального датасета используем нейтральный формат:

```text
dataset/
  vehicle_0001/
    camera_01_frame_001.jpg
    camera_03_frame_215.jpg
  vehicle_0002/
    camera_02_frame_094.jpg
```

Название папки — стабильный `vehicle_id`. Все кадры одного автомобиля должны оставаться в одной части выборки.

## Проверка датасета

```powershell
python scripts/dataset_audit.py dataset --output dataset_report.json
```

Отчёт содержит количество автомобилей и кадров, размеры изображений, повреждённые файлы, точные дубли и классы с единственным изображением.

## Оценка baseline

```powershell
python scripts/evaluate.py dataset --output metrics.json
```

Скрипт считает Recall@1, Recall@5, mAP и время формирования признака. Кадр не сравнивается сам с собой.

## Разбиение без утечки

```powershell
python scripts/split_dataset.py dataset --output split_manifest.json
```

## Калибровка порогов

```powershell
python scripts/calibrate_thresholds.py dataset --output thresholds.json
```

Калибровка отдельно сравнивает пары одного и разных автомобилей, подбирает порог с лучшим F1 и строгий порог с заданной долей ложных совпадений.

## Правило разбиения

Для обучения, подбора параметров и итоговой проверки нужны непересекающиеся списки `vehicle_id`. Если организаторы дают информацию о камерах и времени, дополнительно создаётся межкамерный тест: запрос и правильный ответ должны быть сняты разными камерами.
