# ФАЛЬКОН v3 — инженерная версия, 15 сентября 2026

## Что реализовано и проверено

- CSV image_id,x,y,w,h,vehicle_id; одна строка = один объект, несколько BBox в кадре допустимы.
- Аудит файлов, координат и дублей. Порядок строк сохраняется в embeddings.npy и manifest.json.
- Exact cosine retrieval без матрицы N×N; исключается исходный кадр.
- mAP, Rank-1/5, mINP, отдельные функции калибровки отказа F1/TNR.
- Проверка наличия camera_id при запросе межкамерной оценки. Без camera_id выдаётся только proxy-оценка с явной пометкой.
- ResNet18: нормализованный 512-мерный признак, cross-entropy + batch-hard triplet loss, балансировка ID, аугментации, отложенные ID, сохранение лучшей модели.
- Нейросетевая модель подключается к API через FALCON_CHECKPOINT. Отсутствующий/неправильный checkpoint останавливает запуск.
- BBox в веб-интерфейсе, Top-10 и отображение отказа. Сходство больше не выдаётся за процент вероятности.
- HOST=0.0.0.0 для контейнера, healthcheck, расширенная OpenAPI-схема.

## Запуск

Обычный прототип: распаковать всю папку и открыть start_falcon.bat. Адрес http://127.0.0.1:8000.

Для ML создайте отдельное окружение Python 3.12 и установите requirements-ml.txt. Проверка этого релиза выполнена на CPU с torch 2.6.0 / torchvision 0.21.0. CUDA-сборка требует отдельной установки и проверки совместимости с драйвером.

```powershell
python scripts/challenge.py audit dataset/train.csv dataset/images --output runs/audit
python scripts/train_reid.py dataset/train.csv dataset/images --output runs/model --pretrained
python scripts/challenge.py infer dataset/test.csv dataset/images --checkpoint runs/model/best.pt --output runs/predictions
$env:FALCON_CHECKPOINT="runs/model/best.pt"
python -m app.server
```

--pretrained явно разрешает загрузку начальных весов; инференс всегда читает локальный checkpoint. Для каждого запуска указывайте новую выходную папку.

`--threshold` задаётся только после калибровки на отдельной валидации. Без него экспорт candidates.csv отклоняет все запросы; Top-10 всё равно сохраняется в submission.csv. Значения порогов демо нельзя переносить на новую модель без проверки.

## Существенные незавершённые работы

dataset.zip по указанному пользователем пути имеет размер 0 байт. Настоящее обучение, сравнение экспериментов, 20 примеров ошибок и конкурсные показатели не выполнены. Синтетическая проверка проверяет только исполнение кода.

Схема выходных CSV локальная (row_id необходим для нескольких объектов одного кадра). До сдачи её нужно сверить с образцом организатора; готовность к загрузке на платформу не подтверждена.

Docker daemon не был доступен. Запуск контейнера не проверен. Swagger UI, отдельный сервис ANN/FAISS, миллионный индекс и нагрузочные испытания ещё не реализованы/не проверены. Exact search остаётся O(ND) на запрос.

По ТЗ номера размыты организатором; текущая модель не содержит OCR. Однако отсутствие OCR не доказывает отсутствие использования остаточных признаков номера: это нужно проверить на реальных данных и маскировочных экспериментах. Автоматической гарантии инвариантности к номерам сейчас нет.

Пересечение кадров между train/validation вызывает остановку обучения. В таком случае нужен split по связанным группам кадров/ID. Открытый набор и camera_id отсутствуют, поэтому официальный протокол пока нельзя полностью воспроизвести.

## Источники архитектуры

- ResNet18 implementation and public weight URL: https://github.com/pytorch/vision/blob/main/torchvision/models/resnet.py
- Torchvision ResNet18 API: https://docs.pytorch.org/vision/0.14/models/generated/torchvision.models.resnet18.html
- Loading local tensor checkpoints: https://docs.pytorch.org/docs/stable/generated/torch.load

Выбранные веса ImageNet1K_V1 являются только инициализацией. Происхождение и условия использования всех фактически использованных данных/весов необходимо зафиксировать перед сдачей.
